# 模型训练指南

## 概述

本系统支持三种检测引擎：
1. **规则法（rule_based）**：开箱即用，无需训练，但精度有限
2. **YOLO（yolo）**：深度学习，精度高，需自行训练模型
3. **RKNN（rknn）**：RK3588 NPU 推理，需将 YOLO 模型转换格式

本文档指导您从采集数据到训练出可用的 YOLO 模型。

---

## 一、数据采集

### 1.1 采集要求

- **数量**：建议不少于 5000 张标注图像（每类缺陷至少 500 张）
- **多样性**：
  - 不同糕点品类（面包、蛋糕、酥饼等）
  - 不同光照条件（强光、弱光、侧光）
  - 不同角度和距离
  - 不同异物类型（头发、塑料丝、纸屑、金属屑等）
- **正负样本比例**：合格品 : 不合格品 ≈ 1:1 或 1:2

### 1.2 采集设备

使用最终部署的摄像头采集，确保训练数据和实际推理数据分布一致。

### 1.3 数据组织

```
dataset/
├── images/
│   ├── train/          # 训练集图片（约70%）
│   ├── val/            # 验证集图片（约20%）
│   └── test/           # 测试集图片（约10%）
└── labels/
    ├── train/          # 训练集标注（.txt，YOLO格式）
    ├── val/
    └── test/
```

## 二、数据标注

### 2.1 标注工具

推荐使用 **LabelImg** 或 **Roboflow**（在线工具，免费版够用）：
- LabelImg：https://github.com/HumanSignal/labelImg
- Roboflow：https://roboflow.com/

### 2.2 标注类别

根据实际需求定义类别，建议：

| 类别ID | 类别名 | 说明 |
|--------|--------|------|
| 0 | foreign_object | 异物（头发、塑料等） |
| 1 | defect | 表面缺陷（斑点、空洞） |
| 2 | broken | 破损/缺角 |
| 3 | over_baked | 烤焦 |
| 4 | under_baked | 未烤熟 |

### 2.3 标注格式（YOLO）

每个图片对应一个 `.txt` 文件，每行一个目标：
```
class_id x_center y_center width height
```
坐标均为 0~1 的归一化值。

## 三、模型训练

### 3.1 环境准备

在性能较好的电脑（建议有 NVIDIA GPU）上执行：

```bash
pip install ultralytics
```

### 3.2 创建 data.yaml

```yaml
path: /path/to/dataset
train: images/train
val: images/val
test: images/test

names:
  0: foreign_object
  1: defect
  2: broken
  3: over_baked
  4: under_baked
```

### 3.3 开始训练

```python
from ultralytics import YOLO

# 加载预训练模型（迁移学习，比从零训练快且精度高）
model = YOLO('yolov8n.pt')  # nano版本，边缘部署推荐

# 训练
results = model.train(
    data='data.yaml',
    epochs=100,          # 训练轮次
    imgsz=640,           # 输入尺寸
    batch=16,            # 批次大小（根据显存调整）
    device=0,            # GPU编号，CPU用 'cpu'
    patience=20,         # 早停耐心值
    augment=True,        # 数据增强
    project='runs/train',
    name='pastry_yolov8n',
)
```

或命令行：
```bash
yolo train data=data.yaml model=yolov8n.pt epochs=100 imgsz=640 batch=16
```

### 3.4 模型选择建议

| 模型 | 参数量 | 推理速度(RK3588) | 精度 | 适用场景 |
|------|--------|-------------------|------|----------|
| yolov8n | 3.2M | 80-120 FPS | 基础 | 边缘部署首选 |
| yolov8s | 11.2M | 40-60 FPS | 较好 | 精度要求较高 |
| yolov8m | 25.9M | 20-30 FPS | 好 | 工控机部署 |

> RK3588 推荐使用 yolov8n 或 yolov8s，平衡速度和精度。

## 四、模型评估与导出

### 4.1 评估模型

```bash
yolo val model=runs/train/pastry_yolov8n/weights/best.pt data=data.yaml
```

关注指标：
- **mAP@0.5**：平均精度，目标 > 0.85
- **Precision**：精确率，目标 > 0.90（减少误报）
- **Recall**：召回率，目标 > 0.85（减少漏报）

### 4.2 导出 ONNX（用于笔记本推理）

```bash
yolo export model=best.pt format=onnx opset=12 imgsz=640 simplify=True
```

将生成的 `best.onnx` 放到项目的 `data/models/` 目录。

### 4.3 转换 RKNN（用于 RK3588 NPU 推理）

在 x86 电脑上执行（RK3588 上不能做模型转换）：

```bash
# 安装转换工具
pip install rknn-toolkit2 -i https://pypi.rock-chips.com/simple/

# 转换
python deploy/convert_to_rknn.py --onnx best.onnx --output best.rknn
```

> 建议准备 100-300 张产线图片作为量化数据集，提升 INT8 量化精度：
> ```bash
> ls /path/to/calib_images/*.jpg > dataset.txt
> python deploy/convert_to_rknn.py --onnx best.onnx --output best.rknn --dataset dataset.txt
> ```

将生成的 `best.rknn` 复制到 RK3588 的 `data/models/` 目录。

## 五、配置系统使用训练好的模型

### 笔记本使用 YOLO 模型

修改 `config.yaml`：
```yaml
detection:
  engine: "yolo"
  yolo:
    model_path: "data/models/best.pt"   # 或 best.onnx
    conf_threshold: 0.5
    class_names:
      0: "foreign_object"
      1: "defect"
      2: "broken"
      3: "over_baked"
      4: "under_baked"
```

### RK3588 使用 RKNN 模型

```yaml
detection:
  engine: "rknn"
  rknn:
    model_path: "data/models/best.rknn"
    conf_threshold: 0.5
    class_names:
      0: "foreign_object"
      1: "defect"
```

## 六、数据增强建议

针对糕点异物检测场景，建议使用以下增强策略：

1. **Copy-Paste 增强**：将异物图片粘贴到合格品图片上，扩充异物样本
2. **色彩抖动**：模拟不同烘焙程度和光照变化
3. **模糊增强**：模拟运动模糊和对焦不准
4. **噪声增强**：模拟工业环境的图像噪声
5. **多尺度训练**：适应不同大小的糕点

Ultralytics 已内置大部分增强，可在训练时开启 `augment=True`。

---

## 七、迭代优化策略

1. **第一阶段**：用规则法上线，收集真实产线数据
2. **第二阶段**：标注 1000 张数据，训练初始模型，对比规则法效果
3. **第三阶段**：持续收集误报/漏报样本，每 2000 张增量训练一次
4. **第四阶段**：模型稳定后，在 RK3588 上部署 RKNN 版本
