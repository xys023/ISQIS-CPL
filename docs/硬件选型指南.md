# 硬件选型指南

## 一、边缘计算平台对比

| 平台 | CPU | NPU算力 | 内存 | 价格 | 适用场景 |
|------|-----|---------|------|------|----------|
| **RK3588** | 8核(4xA76+4xA55) | 6 TOPS | 最高32GB | 800-2500元 | 主力推荐，产线部署 |
| **RK3576** | 4核(A72+A53) | 6 TOPS | 最高8GB | 500-1500元 | 性价比之选，单路相机 |
| **RK3568** | 4核A55 | 1 TOPS | 最高8GB | 300-800元 | 轻量场景，规则法检测 |
| **Intel工控机** | i5/i7 | 无(需GPU/加速卡) | 最高32GB | 3000-10000元 | 多路相机，复杂算法 |

### 推荐方案

**主力方案：RK3588**
- 6 TOPS NPU 算力，YOLOv8n 推理可达 80+ FPS
- 支持 8K 视频硬解码，多路摄像头接入
- 工业级版本工作温度 -40°C ~ 85°C
- 推荐型号：香橙派5 Plus、迅为iTOP-RK3588、FCU3501 边缘盒

**预算方案：RK3576**
- 同样 6 TOPS NPU，CPU 性能略低
- 功耗更低（约 3W），适合长时间运行
- 单路 1080p 质检完全够用

## 二、摄像头选型

### USB 摄像头（演示/低成本）
- **推荐**：800万像素 USB3.0 工业摄像头
- **分辨率**：1920×1080 或 3840×2160
- **帧率**：30fps 以上
- **接口**：UVC 免驱，即插即用
- **价格**：200-800 元

### GigE 工业相机（产线部署）
- **推荐**：迈德威视 MV-GE1000C（1000万像素）
- **分辨率**：3840×2748
- **接口**：千兆网口，支持 PoE 供电
- **快门**：全局快门（高速运动不模糊）
- **价格**：1200-1800 元

### MIPI CSI 摄像头（RK3588 直连）
- **推荐**：IMX415 或 OV13850 模组
- **优势**：直接接 RK3588 MIPI 接口，延迟最低
- **价格**：100-300 元

## 三、光源选型

糕点质检对光照要求较高，推荐：

1. **环形无影光源**（必选）
   - 消除阴影，均匀照明糕点表面
   - 直径 100-150mm，白色 LED
   - 价格：300-800 元

2. **多光谱光源**（可选，提升异物检出率）
   - 含紫外波段，增强头发等异物对比度
   - 价格：800-1500 元

3. **背光源**（可选，辅助轮廓检测）
   - 放置在传送带下方，突出糕点轮廓
   - 价格：500-1000 元

## 五、接线说明（RK3588 GPIO）

```
RK3588 GPIO 引脚（40Pin 排针，物理编号）：
  Pin 1: 3.3V    Pin 2: 5V
  Pin 3: GPIO3   Pin 4: 5V
  Pin 5: GPIO4   Pin 6: GND
  ...
  Pin 12: GPIO18  ← 推荐接报警继电器 IN
  Pin 14: GND     ← 继电器 GND
  Pin 2: 5V       ← 继电器 VCC

接线方式：
  RK3588 GPIO18 → 继电器 IN
  RK3588 GND    → 继电器 GND
  RK3588 5V     → 继电器 VCC
  继电器 COM    → 报警器正极
  继电器 NO     → 24V 电源正极
  报警器负极    → 24V 电源负极
```

> 注意：RK3588 GPIO 输出 3.3V，不能直接驱动 24V 报警器，必须通过继电器模块。
