## 一、系统简介

本系统是一套**糕点产线工业级智慧质检系统**，主要功能：

- **实时质检**：通过摄像头拍摄产线上的糕点，自动检测异物（头发等）、破损、烤焦、尺寸异常等缺陷
- **即时报警**：检测到不合格品时自动声光报警
- **数据记录**：自动保存检测日志和不合格品截图
- **Web 监控**：通过浏览器查看实时画面和统计数据

系统支持两种运行环境：

| 环境 | 用途 | 难度 |
|------|------|------|
| 笔记本电脑 | 前期演示、需求对接 | 简单 |
| RK3588 边缘盒 | 产线实际部署 | 中等 |

## 二、硬件准备

### 方案 A：笔记本电脑演示（推荐先做）

你需要准备：
- 一台笔记本电脑（Windows 10/11 或 Ubuntu 20.04+）
- 一个 USB 摄像头（笔记本自带摄像头也可以）
- 网络（下载安装包用）

### 方案 B：RK3588 产线部署

你需要准备：
- RK3588 开发板/边缘计算盒子（推荐 8GB 内存版本）
- USB 工业相机或 MIPI CSI 摄像头
- 声光报警器（24V，接 GPIO）
- 光源（建议环形 LED 光源，确保照明均匀）
- 16GB 以上 TF 卡或 eMMC 存储

## 三、笔记本电脑部署（演示环境）

### 第 1 步：安装 Python

1. 打开浏览器，访问 https://www.python.org/downloads/
2. 下载 **Python 3.10** 或更高版本（推荐 3.10 或 3.11）
3. 运行安装程序，**务必勾选最下方的 "Add Python to PATH"**
4. 点击 "Install Now" 等待安装完成

> 验证：按 `Win+R`，输入 `cmd` 回车，在黑窗口中输入 `python --version`，
> 如果显示 `Python 3.10.x` 就说明安装成功。

### 第 2 步：解压项目文件

1. 将项目压缩包 `pastry_quality_inspection.zip` 解压到一个你容易找到的位置
   - 例如：`D:\糕点质检系统\`
2. 解压后进入文件夹，你应该能看到 `run.py`、`config.yaml` 等文件

### 第 3 步：一键安装

**Windows 用户：**
1. 进入 `deploy` 文件夹
2. **双击** `install_laptop.bat`
3. 等待安装完成（可能需要 3-5 分钟，取决于网速）
4. 看到 "安装完成" 提示后，按任意键关闭窗口

**Ubuntu/Linux 用户：**
1. 打开终端（Terminal）
2. 进入项目目录：
   ```bash
   cd /path/to/pastry_quality_inspection
   ```
3. 执行安装脚本：
   ```bash
   chmod +x deploy/install_laptop.sh
   ./deploy/install_laptop.sh
   ```

### 第 4 步：启动系统

**Windows 用户：**
- 双击 `deploy\start_windows.bat`

**Linux 用户：**
```bash
source venv/bin/activate
python run.py
```

### 第 5 步：打开监控页面

1. 系统启动后，打开浏览器（推荐 Chrome 或 Edge）
2. 在地址栏输入：`http://localhost:8080`
3. 你应该能看到监控大屏，显示摄像头实时画面

### 演示模式（没有摄像头/没有糕点时）

如果暂时没有摄像头或糕点实物，可以使用演示模式：

```bash
# Windows: 在项目目录下执行
venv\Scripts\activate
python run.py --demo

# Linux:
source venv/bin/activate
python run.py --demo
```

演示模式会自动生成模拟的糕点产线画面，并注入随机缺陷，方便您向企业展示系统功能。

## 四、RK3588 边缘设备部署（生产环境）

### 第 1 步：烧录系统

1. 下载 RK3588 官方 Debian 11 或 Ubuntu 20.04 镜像
2. 使用 **Rufus** 或 **balenaEtcher** 将镜像烧录到 TF 卡
3. 将 TF 卡插入 RK3588，上电启动
4. 连接键盘、鼠标、显示器，完成系统初始化

### 第 2 步：连接网络

- 插上网线，或连接 WiFi
- 确认能上网：在终端输入 `ping baidu.com`，有回复说明网络正常

### 第 3 步：复制项目文件

将项目文件夹复制到 RK3588 上，可以用 U 盘或通过网络传输：

```bash
# 如果通过 U 盘，挂载后复制
cp -r /media/usb/pastry_quality_inspection ~/
```

### 第 4 步：一键安装

```bash
cd ~/pastry_quality_inspection
chmod +x deploy/install_rk3588.sh
sudo ./install_rk3588.sh
```

安装脚本会自动完成：
- 系统依赖安装
- Python 虚拟环境创建
- RKNN 运行时安装（NPU 推理）
- GPIO 权限配置
- 开机自启服务配置

### 第 5 步：修改配置文件

用文本编辑器打开 `config.yaml`，修改以下内容：

```yaml
camera:
  source_type: "gstreamer"    # 改为 gstreamer 使用硬解码
  device: "/dev/video0"       # 摄像头设备路径

detection:
  engine: "rknn"              # 改为 rknn 使用 NPU 推理
  rknn:
    model_path: "data/models/best.rknn"   # 你的模型路径

alarm:
  methods: "gpio,console"     # 启用 GPIO 报警
  gpio_pin: 18                # 接报警器的引脚
```

### 第 6 步：启动系统

```bash
source venv/bin/activate
python run.py
```

### 设置开机自启

安装脚本已配置 systemd 服务，手动管理命令：

```bash
sudo systemctl start pastry-inspection    # 启动
sudo systemctl stop pastry-inspection     # 停止
sudo systemctl status pastry-inspection   # 查看状态
sudo systemctl restart pastry-inspection  # 重启
journalctl -u pastry-inspection -f        # 查看实时日志
```

## 五、系统使用说明

### 5.1 监控大屏界面说明

打开 `http://localhost:8080` 后，你会看到：

- **左侧**：实时视频画面（带检测框标注）+ 不合格品截图记录
- **右侧**：统计数据（总检测数、合格品、不合格品、合格率）+ 缺陷分布图 + 系统性能 + 参数配置

### 5.2 检测结果说明

画面上的彩色框代表不同缺陷类型：

| 框颜色 | 缺陷类型 | 说明 |
|--------|----------|------|
| 红色 | 异物 | 头发、塑料等外来物 |
| 橙色 | 破损/缺角 | 糕点形状不完整 |
| 深红 | 烤焦 | 表面颜色过深 |
| 青色 | 未烤熟 | 表面颜色过浅 |
| 黄色 | 表面缺陷 | 斑点、空洞等 |
| 紫色 | 尺寸异常 | 大小不符合标准 |

### 5.3 参数调整

点击右侧"参数配置"的"展开"按钮，可以调整：
- **检测引擎**：规则法（无需训练）/ YOLO / RKNN / 演示
- **置信度阈值**：数值越高，检测越严格，误报越少，但可能漏报
- **检测间隔**：每隔几帧检测一次，数值越大越省 CPU
- **ROI 区域**：只检测画面中央区域，排除背景干扰

调整后点击"保存配置"永久生效。

### 5.4 查看检测记录

- 检测日志保存在 `data/logs/` 目录，按天生成 CSV 文件，可用 Excel 打开
- 不合格品截图保存在 `data/snapshots/` 目录，按日期分子目录

## 六、常见问题解答

### Q1：启动后浏览器打不开页面？

**A**：检查以下几点：
1. 确认终端窗口没有报错，且显示 "Web 服务已启动"
2. 确认端口 8080 没有被其他程序占用
3. 尝试换个浏览器，或用 `http://127.0.0.1:8080` 访问
4. 检查防火墙是否阻止了该端口

### Q2：提示"无法打开摄像头"？

**A**：
1. 检查摄像头是否插好
2. 确认没有其他程序正在使用摄像头（如微信视频、Zoom 等）
3. 尝试换一个 USB 口
4. 在 config.yaml 中修改 `camera.device` 为 1 或其他编号
5. 临时使用演示模式：`python run.py --demo`

### Q3：检测不准确，误报很多？

**A**：
1. 确保光照均匀，避免强光直射和阴影
2. 调整 ROI 区域，只包含糕点传送区域
3. 提高置信度阈值（在参数配置中调整）
4. 规则法精度有限，建议采集数据训练 YOLO 模型（参考 docs/模型训练指南.md）

### Q4：Windows 上提示 "缺少 VCRUNTIME140.dll"？

**A**：下载安装微软 Visual C++ Redistributable：
https://aka.ms/vs/17/release/vc_redist.x64.exe

### Q5：如何在手机上查看监控画面？

**A**：
1. 确保手机和电脑连接同一个 WiFi
2. 查看电脑的局域网 IP 地址（Windows: `ipconfig`，Linux: `ifconfig`）
3. 在手机浏览器输入 `http://电脑IP:8080`
4. 例如：`http://192.168.1.100:8080`

### Q6：RK3588 上 GPIO 报警不工作？

**A**：
1. 确认报警器接线正确（正极接 GPIO 引脚，负极接 GND）
2. 确认使用了正确的引脚编号（config.yaml 中的 gpio_pin）
3. 检查用户是否在 gpio 组：`groups` 命令查看
4. 测试 GPIO 是否正常：`sudo cat /sys/kernel/debug/gpio`

### Q7：如何更新系统到最新版本？

**A**：
1. 备份你的 config.yaml 和 data/ 目录
2. 用新版本替换项目文件
3. 恢复 config.yaml 和 data/ 目录
4. 重新运行安装脚本更新依赖
